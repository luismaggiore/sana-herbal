# Sana Herbal Sciences: maqueta del home

Maqueta del nuevo home de [sanaherbal.com](https://sanaherbal.com), hecha por Maggiore.

- `index.html`: página única (Bootstrap 5.3 por CDN).
- `style.css`: todos los estilos, con escala tipográfica en `:root`.
- `img/`: solo las imágenes que usa la página. Los editables (PSD, AI) y las imágenes sin uso quedan fuera del repo (ver `.gitignore`).

Para verla, abre `index.html` en el navegador o sirve la carpeta con cualquier servidor estático.
